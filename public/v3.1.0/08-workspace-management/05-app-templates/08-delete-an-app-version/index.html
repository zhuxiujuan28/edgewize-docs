删除应用版本

更新时间：2025-07-03 09:03:48
本页目录
  • 前提条件
  • 操作步骤

本节介绍如何在应用模板中删除应用版本。

警告

应用版本删除后无法恢复，请谨慎执行此操作。

前提条件

您需要加入一个边缘企业空间并在企业空间中具有应用/应用版本/应用实例删除权限。有关更多信息，请参阅“企业空间角色”和“企业空间成员”。

操作步骤

  1. 以具有应用/应用版本/应用实例删除权限的用户登录 KubeSphere 企业版 Web 控制台并进入您的边缘企业空间。

  2. 在左侧导航栏选择边缘应用模板。

  3. 在应用模板列表中点击一个应用模板的名称打开其详情页面。

  4. 在应用模板详情页面右侧的应用版本页签，点击并选择需要删除的应用版本，然后点击删除。

  5. 在删除应用版本对话框，输入应用版本的名称，然后点击确定。
